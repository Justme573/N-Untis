# NUntis

Ein inoffizieller WebUntis-Client für Android.

NUntis soll eine moderne und übersichtliche Alternative zur offiziellen WebUntis-App werden – mit Fokus auf einer einfachen Bedienung und einem eigenen Design.

> ⚠️ **Das Projekt befindet sich noch in einer sehr frühen Entwicklungsphase.**
>
> Viele Funktionen, das Design, die Struktur und teilweise auch die technische Umsetzung können sich noch stark verändern. Dinge können außerdem momentan noch unvollständig oder fehlerhaft sein.

## Aktueller Stand

- 🔐 WebUntis Login
- 🏫 Auswahl der Schule
- 📅 Stundenplan
- ❌ Ausgefallene Stunden werden erkannt und können entsprechend dargestellt werden
- 🎨 Eigenes UI/Design in Entwicklung

## Geplant

Unter anderem:

- Weitere WebUntis-Funktionen
- Verbesserte Stundenplan-Darstellung
- Fächerfarben
- Benachrichtigungen
- Weitere Personalisierung
- Weitere Verbesserungen am UI

## Hinweis

NUntis ist ein **inoffizielles Projekt** und steht in keiner Verbindung zu WebUntis bzw. Untis.
